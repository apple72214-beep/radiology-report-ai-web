# مراجعة الحزمة المسلّمة (FastAPI + OpenAI + docxtpl) — وما اعتُمد منها
# Review of the handed-over package (FastAPI + OpenAI + docxtpl) — what was adopted

## ما اعتُمد (adopted)
1. فكرة «ملاحظات خام/إملاء → تقرير مهيكل» كمصدر أولي — صارت حقل «ملاحظات خام / إملاء» في لوحة التأليف (v51) وتدخل في أمر الذكاء.
2. وسوم `<anat>` للمصطلحات التشريحية → غامق في Word (مدعومة منذ v50 في مولّد المتصفح، وفي أمر الذكاء v51).
3. `response_format=json_object` و`temperature=0.1` — معتمدان في مساري المتصفح والسيرفر.
4. قاعدة «لا تكرار جملة» + «تجميع حسب البنية التشريحية» داخل الـsystem prompt.
5. المفتاح في متغير بيئة لا في الكود.

## ما رُفض ولماذا (rejected)
1. **OpenAI/gpt-4o**: استخدام مدفوع برصيد بطاقَة = مخالف لقاعدة المشروع (لا بطاقة إطلاقًا)؛ البديل الافتراضي Groq/OpenRouter/Gemini شرائح مجانية.
2. **Render / AWS / Heroku**: جدران بطاقة/تحقق مالي؛ الاستضافة الوحيدة المسموحة Vercel (هواية بلا بطاقة) أو سيرفر LAN داخلي.
3. **مثال بمفتاح مكتوب داخل الكود** (`api_key="مفتاح_GROQ_…"`) — تسريب؛ المفتاح env فقط.
4. **تنزيل الـWord مباشرًا من السيرفر**: يتخطى مراجعة الطبيب/Tوقيع/بصمة SHA؛ عندنا السيرفر يعيد JSON فقط والتصدير يحدث في المتصفح بعد التحرير.
5. **docxtpl + قالب .docx مفقود**: تبعية ثقيلة وملف غير مرفق؛ مولّد المتصفح يبني OOXML مكافئًا بلا تبعيات (ونقطة Vercel stdlib فقط).
6. **`except Exception as e: HTTPException(500, str(e))`**: تسريب internals؛ رسالتنا عامة (502/503).
7. **حقن اسم الملف** (`patient_name.replace(' ','_')`): غير كافٍ؛ عندنا تعقيم كامل (v50).
8. **CORS `allow_credentials=True` مع methods `*`** و**بلا مصادقة/حد معدل**: نقطة مفتوحة تستهلك حصة المفتاح؛ عندنا same-origin أو Bearer token.
9. **بلا حدود حجم** على raw_notes: عندنا 6000 حرف و60 بندًا و2000 حرف/بند.

## أين يعيش البديل المعتمد
- المتصفح (افتراضي، Offline أولًا): حقل الملاحظات + مزوّد Groq/OpenRouter/Gemini بمفتاح على الجهاز (app.v51.js).
- Vercel اختياري لمفتاح المؤسسة: `api/report_ai.py` (stdlib فقط) يعيد JSON مهيكلًا؛ التحرير/التوقيع/التصدير تبقى في المتصفح.
- سيرفر LAN اختياري لتوليد Word خوادميًا: `backend/report_server_fastapi.py` (v50) — داخلي فقط.
