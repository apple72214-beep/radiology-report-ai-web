# دليل استخدام منصة Radiology report AI (نسخة المتصفح)

منصة تقارير أشعة تعمل بالكامل داخل متصفحك: لا سيرفر، لا بيانات تغادر جهازك، وبعد أول تشغيل ناجح تُخزَّن النسخة على جهازك وتعمل دون إنترنت.

## 1) الفتح أول مرة
1. افتح الرابط: `https://radiology-report-ai-web.vercel.app/x` (أو أي مسار طازج يُعطى لك: `/y` أو `/z` أو `/r1/start.html`).
2. انتظر حتى تظهر الواجهة الكاملة (سطر التحميل قد يعدّ ثوانٍ على الشبكات الضعيفة — دعه يواصل).
3. بعد أول نجاح يُسجَّل «عامل الخدمة» (SW): من thereafter افتح الرابط المعتاد `.../start.html` وسيعمل حتى بدون شبكة.
4. اختياري (يُستحسن): من قائمة المتصفح ← «إضافة إلى الشاشة الرئيسية» ليصير أيقونة كتطبيق.

## 2) إدخال الدراسات
- **ملفات DICOM من جهازك**: «اختيار الملفات» ← اختر `.dcm` أو `.zip` منها ← «رفع وتحليل». تُفرز آليًا (حرج / استشارة / روتيني) وتدخل قائمة العمل.
- **تجربة سريعة بلا ملفات**: «توليد ديمو» ← دراستان جاهزتان (DEMO-0001 حرج، DEMO-0002 روتيني).
- الشارة الحمراء = حرج (عدم تناظر بين ساحتي الرئتين)، الزرقاء = استشارة، الخضراء = روتيني.

## 3) العارض
- «عرض» بجانب أي دراسة تفتح العارض.
- **الشريحة**: المنزلق يقلّب شرائح الدراسة (متزامن مع كل الألواح).
- **قطع**: قائمة النوافذ (رئات/منصف/عظم…) لتغيير تباين العرض.
- **1:1** تكبير طبيعي، والسحب يحرك الصورة.
- **قياس**: وضع القياسات (مسافة بالمم عبر بيانات البكسل، زاوية، ومنطقة ROI بمتوسط HU) ثم «مسح القياسات» يفرغها.

## 4) المقارنة مع دراسة سابقة (باب v1.1)
1. افتح الدراسة الحالية في العارض.
2. اضغط «مقارنة» واختر الدراسة الأخرى من القائمة المجاورة.
3. تظهر ثلاثة ألواح: **الحالية / السابقة-الأخرى / خريطة الفرق (أحمر = ساخن)** + سطر الإحصاء: «متوسط الفرق … والنقاط الساخنة …% (عتبة 0.25 بعد التطبيع)».
4. تُحفظ النتيجة مع الدراسة وتدخل تلقائيًا مسودة التقرير.

## 5) التقرير والتوقيع والتصدير
1. «توليد مسودة التقرير (ع/EN)»: مسودة عربية وإنجليزية (انطباع، فرز آلي، سياق، مقارنة) — **قرار داعم وليس تشخيصًا**.
   نفس الضغطة تنزل تلقائيًا ملف Word إنجليزي `rrai-report-EN-<patient>.docx` بالقالب السريري (عنوان كحلي مركزي، كتلة بيانات المريض، عناوين TECHNIQUE/FINDINGS/IMPRESSION زرقاء، صندوق انطباع مظلل، بلوك Reported by يمينًا، وبصمة SHA-256 أسفله). زر مستقل «تصدير Word (قالب EN)» بجانب زر Word القديم يعيد توليده بعد التعديل.
2. راجع النص وصحّح ما يلزم يدويًا.
3. أدخل اسمك ورقم ترخيصك/النقابة (اختياري لكنه يظهر في بلوك التوقيع ويُحفظ مع الدراسة).
4. «توقيع وتصدير PDF» أو «توقيع وتصدير Word»: يُحسب SHA-256 للوثيقة ويُدرج مع التوقيع؛ افتح الملف في Xodo (PDF) أو WPS Office Lite (Word).
5. ترويسة مؤسستك: «إعدادات ترويسة المؤسسة» ← اكتب اسم المنصة بالعربي/الإنجليزي ← «حفظ الترويسة» فتظهر في كل التقارير.

## 6 حلقة الاستشارة عن بُعد (تيلراديولوجي)
- عندك حالة تريد رأي زميل: «تصدير حزمة استشارة» (نص+لقطة+بيانات) ← انسخها أو أرسل الملف.
- الزميل: «استيراد حزمة استشارة» أو «استيراد من الحافظة» أو «استيراد آخر حزمة مصدّرة» ← تدخل الحالة قائمته مع لقطة وسياق، ويردّ بمسودة تقريره الخاصة.
- التحقق مغلق: أي حزمة معدّلة تُرفض برسالة واضحة.

## 7) الخصوصية والتنظيف
- كل المعالجة داخل متصفحك؛ لا شيء يُرفع لأي سيرفر.
- «تفريغ القائمة من الجهاز» يحذف الدراسات من تخزين الجهاز نهائيًا.
- لإزالة كل أثر: إعدادات Chrome ← إعدادات الموقع ← مسح بيانات الموقع.

## 8) إذا تعثّر الفتح على شبكة محصورة
1. صفحة التشخيص: `.../d` تعرض مرحلة الإقلاع وآخر خطأ وحالة SW ومعها أزرار إنقاذ.
2. جرّب مسارًا طازجًا بالترتيب: `/x` ثم `/y` ثم `/z` ثم `/r1/start.html`.
3. بدّل الواي فاي إلى بيانات الجوال (أو العكس) وأعد الفتح.
4. لا تمسح بيانات الموقع إلا كحل أخير (يضيع التخزين المحلي).

## تذكير سريري
المنظومة **نظام دعم قرار**: كل مسودة تحمل إخلاء المسؤولية، والاعتماد النهائي مسؤولية الطبيب المختص الموقع.

## 9) ربط PACS المستشفى أو تطبيق قارئ DICOM (جسر Orthanc)
حوار DICOM الكلاسيكي (AE title / منفذ 11112 / C-GET / C-MOVE) بروتوكول TCP خام لا تتكلمه المتصفحات؛ الجسر هو **Orthanc** المضمّن في حزمة الطرف:
1. على جهاز داخل الشبكة: `docker compose -f docker/docker-compose.yml up -d` — يشغل المنصة (8080) **ومعه Orthanc** (منفذ DICOM‏ 4242 وDICOMweb على `/dicom-web/` خلف nginx المضمّن بترويسات CORS).
2. عدّل `docker/orthanc.json`: ضع في `DicomModalities.hospital_pacs` نفس قيم حوار «New server» (AE title للأرشيف، عنوانه، منفذه) وأعد التشغيل؛ اسحب الدراسات عبر REST أو اجعل الأرشيف يرسل C-MOVE إلى AET‏ `RRAI`.
3. في المنصة افتح «سحب من PACS (DICOMweb)» وأدخل `http://<edge-ip>:8080/dicom-web` — نفس الأصل بلا وكيل؛ العناوين الداخلية تُطلب مباشرة وأطراف الإنترنت العامة تمر عبر وكيل `/api/dicomweb`.
4. تطبيق القارئ على هاتفك يربط على **نفس Orthanc**: Name حر، AE title‏ `RRAI`، Host عنوان جهاز الطرف، Port‏ `4242`، Retrieve‏ C-GET — فيقرأ الاثنان نفس مخزن الحالات.
بديل بلا سيرفر: صدّر/شارك ملفات `.dcm` من تطبيق القارئ وارفعها في المنصة عبر «اختيار الملفات».
5. زر «سحب من رابط تنزيل (WeTransfer/ZIP/DICOM)» له منذ v42 حقل مستقل باسم «رابط التنزيل» داخل نفس القائمة؛ الصق فيه رابط WeTransfer أو ZIP أو `.dcm` مباشر ثم اضغط الزر. إن تركت الحقل فارغًا يفتح الزر نافذة لصق نظامية، والرابط يُستخرج حتى لو لصقته داخل جملة أو بلا `https://`. روابط WeTransfer تُفك عبر خادم المنصة؛ وإن طلبت WeTransfer تحققًا بشريًا من الخادم تظهر رسالة واضحة والبديل «اختيار الملفات» أو رابط ZIP مباشر.
